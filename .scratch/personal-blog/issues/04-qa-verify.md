# 04 — 校验构建产物满足验收清单（QA gate）

**What to build:** 访客打开构建后的博客即可获得一整套完整可用的阅读体验：首页显示博客名称、作者昵称、欢迎语与各分类/文章入口；「生活 / 迷思 / 足球」三个分类页、「关于」页、「友链」页均可访问并展示各自内容；文章内的双向链接可点击跳转到关联笔记；关系图谱、搜索框、深色/浅色模式切换、反向链接（backlinks）、目录（TOC）、面包屑、侧栏文件树、链接悬停预览均可用；移动端可正常阅读；访问不存在的地址显示友好的 404 页；站点还产出可用的 sitemap 与 RSS 订阅源；中文界面与内容正确显示、无乱码；带 draft 标记的文章与 private/templates/.obsidian 等目录的内容不出现在线上。作者运行一次构建，即可得到一份逐项通过该验收清单、可放心发布的静态站点。

**Blocked by:** 01 — 清理 Quartz 模板残留，让仓库成为 Niccolo's Viola Garden；02 — 用真实内容替换占位页（首页 / 关于 / 友链）；03 — 每个分类补一篇真实示范文章（生活 / 迷思 / 足球）

**Status:** ready-for-agent

- [ ] 运行构建命令以退出码 0 成功完成，且产物目录中生成静态站点文件。
- [ ] 首页可访问，显示博客名称 "Niccolo's Viola Garden" 与作者昵称。
- [ ] 首页显示简短欢迎语，并提供指向各分类与文章的入口链接。
- [ ] 「生活」「迷思」「足球」三个分类页均可访问，各自列出对应分类下的文章。
- [ ] 「关于」页面可访问并展示作者介绍。
- [ ] 「友链」页面可访问并展示推荐网站。
- [ ] 文章内的双向链接被渲染为可点击的超链接，点击后能跳转到对应笔记。
- [ ] 页面上存在关系图谱组件，可展示笔记之间的连接关系。
- [ ] 页面上存在搜索框，输入关键词能返回相关文章结果。
- [ ] 页面工具栏存在深色/浅色模式切换按钮，点击后站点在两种配色间切换。
- [ ] 文章底部显示反向链接（backlinks）区块，列出引用了当前文章的其他笔记。
- [ ] 长文章显示目录（TOC），点击目录项可跳转到对应章节。
- [ ] 文章页面显示面包屑导航，点击可返回上级目录或首页。
- [ ] 侧栏文件树（explorer）可展开/收起目录，展示站点目录结构。
- [ ] 鼠标悬停文章内链时，显示目标笔记的内容预览弹层（popover）。
- [ ] 在手机或平板宽度（窄视口）下打开首页与文章页，页面正常显示、无横向滚动、内容不溢出。
- [ ] 访问不存在的地址时，显示友好的 404 页面而非报错或白屏。
- [ ] 站点整体呈现紫（#7c3aed）+ 白 + 红（#c62839）的紫百合配色，浅色/深色模式分别符合 spec 中定义的两套色值。
- [ ] 站点产出 sitemap.xml，且内容为结构有效的站点地图，包含各页面地址。
- [ ] 站点产出 RSS 订阅源（index.xml），且内容为有效的订阅源，包含文章条目。
- [ ] 页面中文文本正确显示、无乱码或字体缺失，界面文案（如「最近文章」）以中文呈现。
- [ ] 带 draft: true 标记的文章不出现在构建产物、任何页面或索引中。
- [ ] private、templates、.obsidian 目录下的内容不出现在构建产物中。
