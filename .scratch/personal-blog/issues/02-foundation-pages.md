# 02 — 用真实内容替换占位页（首页 / 关于 / 友链）

**What to build:** 访客打开博客，首页立即展示博客名称「Niccolo's Viola Garden」、作者昵称、一段简短的中文欢迎语，以及通往「生活 / 迷思 / 足球」各分类和具体文章的入口，让访客一眼知道这是谁、写什么的博客并能快速找到想读的内容；访客还能从站点导航打开「关于」页面了解作者是谁、打开「友链」页面查看作者推荐的网站。这三个页面全部是作者自己的中文真实内容，不再出现 Quartz 模板的英文占位文字。

**Blocked by:** None — can start immediately

**Status:** ready-for-human

- [ ] 打开站点首页（根路径），能看到博客名称「Niccolo's Viola Garden」。
- [ ] 首页显示作者昵称，访客能据此知道博主是谁。
- [ ] 首页显示一段简短的中文欢迎语，说明博客写什么。
- [ ] 首页提供通往「生活」「迷思」「足球」三个分类的入口，点击任一入口能到达对应的分类内容。
- [ ] 首页提供通往具体文章的入口（例如文章列表或最近文章链接），点击能进入文章正文。
- [ ] 首页不再出现 Quartz 模板的英文占位内容，全部替换为作者自己的中文内容。
- [ ] 站点存在一个「关于」页面，访客能从站点导航（侧栏或顶部导航）找到并打开它。
- [ ] 「关于」页面的内容是作者的自我介绍，访客能从中了解作者是谁、在做什么。
- [ ] 站点存在一个「友链」页面，访客能从站点导航（侧栏或顶部导航）找到并打开它。
- [ ] 「友链」页面列出作者推荐的网站，每个条目都是可见且可点击跳转的外部链接。
- [ ] 首页、关于、友链三个页面的中文均正确渲染，无乱码、无方框或字体缺失。
