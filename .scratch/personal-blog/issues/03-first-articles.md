# 03 — 每个分类补一篇真实示范文章（生活 / 迷思 / 足球）

**What to build:** 为博客的三大分类——生活、迷思、足球——各写一篇真实的中文示范文章，用真实内容把博客要支持的写作特性完整跑通一遍：每篇都有标题、日期、标签和摘要元数据；文章之间用 [[双向链接]] 互相引用，形成反向链接并进入关系图谱；正文演示 callout 提示块、mermaid 图、LaTeX 公式、高亮、删除线、复选框和箭头等 Obsidian 语法。构建后，访客从首页或分类页进入任一分类，都能看到该分类下有一篇真实可读的文章；点开文章，元数据、日期、标签、双向链接、各类排版语法都按 Obsidian 的观感正确渲染，长文有目录，侧栏「最近文章」也会列出这些新文章。

**Blocked by:** 02 — 用真实内容替换占位页（首页 / 关于 / 友链）

**Status:** ready-for-human

- [ ] 运行构建命令后能成功产出站点（正常退出、不报错），新增内容不破坏构建。
- [ ] 构建后，生活、迷思、足球三个分类页各自都能看到至少一篇真实、完整的示范文章（非空目录、非模板占位内容）。
- [ ] 三篇文章的标题与正文均为作者原创的中文内容，主题分别贴合「生活」「迷思」「足球」。
- [ ] 每篇文章通过 frontmatter 设置了 title、date（YYYY-MM-DD 格式）、tags（列表）与 description，且这些字段在页面上有对应可见效果：标题正确显示、描述可见、标签可点击。
- [ ] 至少一篇文章通过 frontmatter 设置了 aliases 字段，且该别名在页面的元数据区可见。
- [ ] 每篇文章页面显示发布日期，格式为 YYYY-MM-DD。
- [ ] 至少一篇文章包含 [[wikilink]] 形式的内链，构建后渲染为可点击链接并能跳转到目标笔记页面。
- [ ] 被内链指向的目标笔记页面真实存在，且其页面底部「反向链接」区列出了指向它的来源文章。
- [ ] 三篇文章之间存在至少一条 wikilink 连接，构建后的关系图谱中能看到这些文章对应的节点及其连线。
- [ ] 当一篇文章被改名或移动到新路径后，指向它旧地址的链接仍能跳转到该文章（别名重定向生效），不出现死链。
- [ ] 至少一篇文章包含 callout 提示块（如 [!note]/[!tip]），构建后渲染为醒目的提示块样式，而不是显示原始语法文本。
- [ ] 至少一篇文章包含 LaTeX 公式，构建后渲染为清晰可读的数学公式，而不是显示原始 $...$ 符号文本。
- [ ] 至少一篇文章包含 mermaid 代码块，构建后渲染为可视化图表，而不是显示原始代码文本。
- [ ] 至少一篇文章包含高亮、删除线、复选框和箭头语法，构建后分别渲染为带底色高亮、带删除线文字、复选框和 → 箭头，与 Obsidian 显示一致。
- [ ] 所有文章的中文文本在构建后正确显示，无乱码、无方块或问号等字体缺失迹象。
- [ ] 较长的文章在构建后显示目录（TOC），点击目录项可跳转到对应章节。
- [ ] 三篇新文章出现在侧栏「最近文章」列表中。
